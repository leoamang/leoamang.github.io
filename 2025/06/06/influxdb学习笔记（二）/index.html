1.2管理任务

创建任务*3

可以使用三种方式创建任务

  • InfluxDB UI（主要）
  • influx CLI
  • InfluxDB API

在 InfluxDB UI 中创建任务

  • 从 Data Explorer 创建任务
  1. 在左侧的导航菜单中，选择 Data Explorer。
  2. 构建查询，然后单击右上角的 Save As。
  3. 选择 Task （任务） 标题。
  4. 指定任务选项。
  5. 单击 Save as Task（另存为任务）
  • 在任务 UI 中创建任务
  1. 在左侧的导航菜单中，选择 Tasks （任务）。
  2. 单击右上角的 Create Task。
  3. 在左侧面板中，指定任务选项。
  4. 在右侧面板中，输入任务脚本。
  5. 单击右上角的 Save。
  • 导入任务
  1. 在左侧的导航菜单中，选择 Tasks （任务）。
  2. 单击右上角的+ Create Task→import task。
  3. 在左侧面板中，指定任务选项。
  4. 在代码编辑器中将原始 Flux 任务粘贴到任务选项字段的右侧。
  5. 单击右上角的 Save。
  • 从模板创建任务
  1. 在左侧的导航菜单中，选择 Settings > Templates。
  2. 找到您要使用的模板，然后单击其 Resources 列表以展开资源列表。
  3. 在 Resources （资源） 列表中，单击要使用的任务。
  • 克隆任务
  1. 在左侧的导航菜单中，选择 Tasks （任务）。
  2. 找到要克隆的任务，然后单击位于任务名称最右侧的图标。
  3. 单击 Clone （克隆）。

查看任务*3

在 InfluxDB UI 中查看任务并筛选

  1. 单击左侧导航栏中的 Tasks 图标可查看任务列表。
  2. 单击 Show Inactive 切换以包含或排除 列表中的非活动任务。
  3. 在 Filter tasks 字段中输入文本，以按名称或标签搜索任务。
  4. 单击任何列的标题可按该字段排序。

运行任务*3

从 InfluxDB UI 运行任务

  1. 在左侧的导航菜单中，选择 Tasks （任务）。
  2. 将鼠标悬停在要运行的任务上，然后单击图标。
  3. 选择 Run Task（运行任务）。

查看运行历史记录*3

  1. 在左侧的导航菜单中，选择 Tasks （任务）。
  2. 将鼠标悬停在要运行的任务上，然后单击名称。
  3. 要查看与运行关联的日志，单击任务运行历史记录中该运行旁边的 View Logs （查看日志）。

更新任务（edit）*3

  1. 在左侧的导航菜单中，选择 Tasks （任务）。
  2. 找到要编辑的任务，然后单击任务名称最右侧的设置图标。
  3. 单击 Edit（编辑）。
  4. 单击右上角的 Save。

导出任务

  1. 在左侧的导航菜单中，选择 Tasks （任务）。
  2. 在任务列表中，将鼠标悬停在要导出的任务上，然后单击 出现的图标。
  3. 选择 Export （导出），导出为json格式文件

删除任务*3

  1. 在左侧的导航菜单中，选择 Tasks （任务）
  2. 在任务列表中，将鼠标悬停在要删除的任务上。
  3. 单击最右侧的 Delete。
  4. 单击 Confirm。

1.4任务配置选项

任务配置选项包括：

  1. name

字符串 ，必须的参数

  1. every

任务运行的时间间隔。

  1. cron

字符串，定义任务所依据的计划，corn调度基于系统时间

  1. offset

延迟任务的执行，但保留原始时间范围。 例如，如果任务要在整点运行，则偏移量会将其延迟到 10 分钟，但任务中定义的所有时间范围都相对指定的执行时间。 一个常见的使用案例是偏移执行，以考虑可能延迟到达的数据。
