基本概念

1.数据组织

​ InfluxDB 数据模型将时间序列数据组织到存储Bucket和Measurement中。 一个存储桶可以包含多个测量值。测量包含多个 标签和字段。

  • Bucket：存储时间序列数据的命名位置。 一个存储桶可以包含多个测量值。
    • Measurement：时间序列数据的逻辑分组。 给定测量中的所有点都应具有相同的标签。 一个测量包含多个标签和字段。
      • Tags：值不同但不经常更改的键值对。 标签用于存储每个点的元数据，例如 用于识别数据源的东西，如主机、位置、站点等。
      • Fields：值随时间变化的键值对，例如：温度、压力、股票价格等。
      • Timestamp：与数据关联的时间戳。 当存储在磁盘上并进行查询时，所有数据都按时间排序。

和mysql数据库对比：

mysql influxdb
Database Bucket
Table _Measurement
Tags（属于什么类型）
column __field,__timestamp，__value 

    - **point**：由*其Measurement、*tag keys,*、*tag values*、*field key和*timestamp*标识的单个数据记录。
    - **Series**：一组具有相同*Measurement、*tag keys和 *tag values的点。

​ 设置初始用户

  1. 输入初始用户的 Username。

  2. 输入用户的 Password （密码） 和 Confirm Password （确认密码）。

  3. 输入您的初始组织名称。

  4. 输入您的初始 Bucket Name （存储桶名称）。

  5. 单击 Continue（继续）。

  6. 复制提供的作员 API 令牌并将其存储起来以安全保存。

    4. 复制生成的令牌并将其存储起来以安全保存。

    创建桶

    1. 导航到 Load Data > Buckets （加载数据存储桶）。
    2. 单击 + Create bucket（创建存储桶）。
    3. 提供存储桶名称 （Baosteel） 并选择 Never 创建具有无限保留期的存储桶。
    4. 单击 Create。

5.1.创建控制面板

  1. 登录并选择左侧导航栏中的 Dashboards。

  1. 单击 + Create Dashboard 并选择 New Dashboard。

  2. 单击 Name this Dashboard （命名此控制面板） 并提供控制面板的名称。 在本教程中，使用 “Getting Started Dashboard”（入门控制面板）。

5.2.创建仪表板单元格

  1. 点击仪表盘名字进入界面，单击 Add Cell （添加单元格）。

  1. 单击 Name this Cell （命名此单元格） 并提供单元格的名称。 在本教程中，我们将使用 “Getting Started Dashboard cells”。

  2. （可选）从可视化下拉菜单中选择可视化类型。 有许多不同的可视化类型可用。 在本教程中，使用默认的 Graph visualization（图形可视化）。

  3. 使用查询时间范围选择器选择绝对时间范围，该时间范围 covers 包括 “开始写入 InfluxDB” 中写入的数据的时间范围：2022-01-01T08：00：00Z 到 2022-01-01T20：00：01Z。查询时间范围选择器默认查询过去一小时的数据 （ 过去 1 小时）。 单击 Time range selector 下拉菜单，然后选择 Custom Time Range （自定义时间范围）。

  1. 使用 Query Builder 选择要查询的测量、字段和标记：
  • 在 From （从） 列中，选择存储桶。
  • 在 Filter （筛选器） 列中，选择主测量值。
  • 在下一个 Filter 列中，选择temp字段。
  • 在下一个 Filter （筛选器） 列中，选择 room 标签和 Kitchen 标签值。
  1. 或者选择script editor的方式查询数据
  2. 单击 Submit 以运行查询并可视化结果。
  3. 单击√以保存单元格并返回到仪表板。

5.3.创建和使用仪表板变量

InfluxDB 控制面板单元使用控制面板变量动态更改 单元格查询的特定部分。查询生成器使用以下预定义的控制面板变量自动构建查询： 每个选项都由控制面板中的选择控制：

  • v.timeRangeStart：时间范围选择器指定的查询时间范围的开始时间。
  • v.timeRangeStop：时间范围选择器指定的查询时间范围的停止时间。
  • v.windowPeriod：使用的窗口周期将数据下采样到每个像素1点单元格可视化。此变量的值由单元格的像素宽度确定。
  1. 创建自定义控制面板变量

  • 单击 + Create Variable 并选择 New Variable。
  • 为变量命名。在本教程中，将变量命名为 “room”。
  • 选择默认的 Query dashboard 变量类型。
  • 输入以下 Flux 查询以返回所有不同的标记值在存储桶中。
  • 单击 Create Variable。

  1. 使用自定义控制面板变量

  • 通过单击 Dashboards （控制面板） 导航到 Getting Started Dashboard （入门控制面板） 左侧导航栏，然后单击控制面板的名称。

  • 单击 刚才创建的仪表盘单元 并选择配置按钮。

  • 单击 Script Editor 以编辑 Flux 查询。

  • 在 Flux 查询的第 5 行，替换为以使用 Dashboard 变量的选定值。

  • 单击√以保存单元格并返回到仪表板。
