1.管理influxdb控制面板

​ 在 InfluxDB 用户界面 （UI） 中创建、编辑和管理自定义控制面板。

1.1 创建控制面板

​ 在 InfluxDB 用户界面 （UI） 中创建新控制面板或导入现有控制面板。

创建新的控制面板

  1. 在influxDB UI界面左侧的导航菜单中，选择 Boards （Dashboards）。
  2. 单击右上角的 Create Dashboard 菜单，然后选择 New Dashboard。
  3. 在左上角的 Name this dashboard （命名此控制面板） 字段中输入控制面板的名称。

导入现有控制面板

  1. 在左侧的导航菜单中，选择 Boards （Dashboards）。

  2. 单击右上角的 Create Dashboard 菜单，然后选择 Import Dashboard。

  3. 在显示的窗口中：

    • 选择 上传文件 以拖放或选择一个文件。
    • 选择 Paste JSON （粘贴 JSON） 以粘贴 JSON。

  4. 单击 Import JSON as Dashboard（将 JSON 导入为控制面板）。

克隆控制面板

  1. 在左侧的导航菜单中，选择 Boards （Dashboards）。

  2. 点击仪表盘右上角的设置按钮，单击clone

1.2 控制仪表板

·添加单元格（参考上一篇笔记的第5节）

  1. 在左侧的导航菜单中，选择 Boards （Dashboards）。
  2. 单击对应的仪表盘名称，进入仪表盘界面
  3. 在控制面板中，单击 Add Cell （添加单元格），在左上角输入单元格的名称。
  4. 按照 Explore metrics 中的说明在 Data Explorer 中创建查询。可以通过可视化选择或者脚本的方式创建query
  5. 单击复选标记图标 √将单元格保存到控制面板。

·向仪表盘添加注释

  1. 在控制面板中，单击左上角的 Add Note （添加注释）。
  2. 在出现的窗口中输入注释。可以使用 Markdown 语法来格式化您的笔记。
  3. 要预览 Markdown 格式，请单击 Preview （预览） 选项。
  4. 单击 Save （保存）。

单击刷新按钮 （） 以手动刷新控制面板的数据。

·设置自动刷新时间

·选择时区

在控制面板中，单击timezone下拉列表选择用于控制版面的时区。

·选择时间范围

  1. 从下拉菜单中的时间范围选项中进行选择
  2. 选择 Custom Time Range （自定义时间范围） 以输入精确到纳秒的自定义时间范围。 默认时间范围为 5 分钟。

1.3导出仪表板

  1. 在左侧的导航菜单中，选择 Boards （Dashboards）。

​ 在 InfluxDB 用户界面 （UI） 中创建、管理和使用自定义控制面板变量。

2.1创建变量

​ 在 Data Explorer 中、从 Organization 页面创建控制面板变量，或导入变量。

​ 在 Data Explorer 中，从 Settings 部分创建控制面板变量，或导入变量。变量名称必须唯一

变量名称限制

变量名称必须以字母或下划线_开头。

以下名称不能用作功能板变量，因为它们是 Flux 中的保留关键字：、、 和 。and``import``not``return``option``test``empty``in``or``package``builtin

1. 在 Data Explorer 中创建变量

  1. 单击侧边栏中的 Data Explorer 图标
  2. 使用 Query Builder 或 Script Editor 构建查询。
  3. 使用 Table visualization type 或启用 View Raw Data 选项来查看可读的查询结果。
  4. 单击右上角的 Save As 。
  5. 在显示的窗口中，选择 Variable （变量）。
  6. 在 Name （名称） 字段中输入变量的名称。
  7. 单击 Create。

2. 在 Settings 部分创建变量

  1. 单击导航栏中的 Settings 图标。
  2. 选择 Variables 选项卡。
  3. 输入变量的名称。
  4. 选择变量类型。
  5. 输入相应的变量信息。
  6. 单击 Create。

3.导入变量

  1. 单击导航栏中的 Settings 图标。
  2. 选择 Variables 选项卡。
  3. 单击 Create Variable 下拉菜单，然后选择 Import Variable。
  4. 在显示的窗口中：
  • 选择 上传文件 以拖放或选择一个文件。
  • 选择 Paste JSON （粘贴 JSON） 以粘贴 JSON。
  1. 单击 Import JSON as Variable。

2.2更新变量

更新 InfluxDB 用户界面中的控制面板变量。

  1. 单击导航栏中的 Settings 图标。
  2. 选择 Variables 选项卡，更改变量的名称（变量选项卡中右边的单击设置按钮之后下下拉栏rename）。
  3. 从列表中单击变量的名称。
  4. 更新变量类型和相关信息。
  5. 单击 Submit。

3.在influxDB UI中管理标签

标签是一种将可视化元数据添加到 InfluxDB UI 中的控制面板、任务和其他项目的方法。 就是给控制面板、桶等加个标记，

在左侧的导航菜单中，选择 Settings > Labels。

3.1创建标签

  1. 单击 Create Label （创建标签）。
  2. 输入标签的 Name （名称）。
  3. 输入标签的描述 （Optional）。
  4. 为标签选择 Color （颜色）。
  5. 单击 Create Label （创建标签）。

3.2编辑标签

  1. 在标签列表视图中，单击要编辑的标签的名称。 此时将显示 Edit Label 。
  2. 对标签进行所需的更改。
  3. 单击 Save Changes。

3.3删除标签

  1. 在标签列表视图中，将鼠标悬停在要删除的标签上，然后单击 。
  2. 单击 Delete （删除）。

3.4 添加标签

  1. 在功能板、任务或其他资产的列表视图中，将鼠标悬停在要添加标签的项目上。
  2. 单击＋图标。 此时将显示 Add Labels。
  3. 键入要添加的标签的名称，以筛选可用标签的列表。 点击您要添加的标签。

4.在仪表盘中使用注释

4.1创建批注

  1. 在左侧的导航菜单中，选择 Boards （Dashboards）。
  2. 选择要向其添加注释的现有仪表板，或创建一个新仪表板，然后单击 Add note （注释） 按钮。
  3. 在仪表板单元格中，执行以下作之一：
    • 按住 Shift 键并单击要注释的时间的图形。
    • 要向时间范围添加注释，请按 Shift 键，单击开始时间，然后将光标拖动到结束时间。

  1. 在 Add Annotation （添加注释） 页面上：

​ - 验证时间或时间范围，并根据需要进行更新。

​ - 输入要与所选时间或时间范围关联的消息（最多 255 个字符）。

​ - 单击 Save Annotation （保存注释）。批注将显示在单元格中（虚线表示所选时间或时间范围）。

4.2编辑批注

  1. 在左侧的导航菜单中，选择 Boards （Dashboards）。
  2. 打开包含要编辑的注释的仪表板，然后单击注释将其打开。
  3. 更新文本（最多 255 个字符）或时间戳，然后单击 Save Annotation。

4.3查看或隐藏批注

  1. 在左侧的导航菜单中，选择 Boards （Dashboards）。
  2. 打开带有注释的仪表板：
    • 要隐藏注释，请单击Enable Annotations 复选框。当注释被隐藏时，复选框未被选中。
    • 要显示注释，请单击 Enable Annotations 按钮。当注释可见时，复选框被选中。

4.4删除批注

  1. 在左侧的导航菜单中，选择 Boards （Dashboards）。
  2. 打开包含要删除的注释的仪表板，单击虚线注释线，然后单击 Delete Annotation。
